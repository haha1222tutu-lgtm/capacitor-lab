02

改变板间距离 d，电容值如何变化？ Control variable · C–d

答：由平行板电容器公式可知，当极板面积 S 和介质相对介电常数 εr 保持不变时，电容 C 与板间距离 d 成反比：

C = ε0εrS / d ⇒ C ∝ 1/d

因此，d 增大时 C 减小，d 减小时 C 增大；若 d 变为原来的 n 倍，C 就变为原来的 1/n。以 S = 100 cm²、εr = 1.0006（空气）为例：

板间距离 d电容 C相对变化
1.00 mm88.59 pF2.00 ×
2.00 mm44.30 pF1.00 ×（基准）
4.00 mm22.15 pF0.50 ×
补充：若保持电荷量 Q 不变，U = Q/C 会随 d 增大而增大，而 E = Q/(ε₀εᵣS) 与 d 无关；若保持电压 U 不变，Q = CU 会随 d 增大而减小，E = U/d 也随 d 增大而减小。平台中的两种模式可分别验证。
03

代码中的核心物理公式是什么？ Core physics · source code

答：核心是平行板电容器的电容公式，以及由它导出的电压、场强、面电荷密度和储能公式：

C = ε0εrS / d　·　σ = Q/S　·　E = σ/(ε0εr) = U/d　·　W = ½CU²

代码先统一单位（cm² → m²、mm → m），再计算电容；固定电荷时由 U = Q/C 求电压，固定电压时由 Q = CU 求电荷量。

// 核心物理计算（节选）
const EPS0 = 8.8541878128e-12;       // 真空介电常数 F/m
const S = state.S * 1e-4;            // cm² → m²
const d = state.d * 1e-3;            // mm → m
const C = EPS0 * state.er * S / d;     // 电容 F
const Q = state.mode === 'charge'
  ? state.Q * 1e-9 : C * state.U;
const U = state.mode === 'charge'
  ? Q / C : state.U;
const E = U / d;                       // 场强 V/m
const W = 0.5 * C * U * U;              // 储能 J
小位移线性化（传感模块）：C(d₀+Δx) = ε₀εᵣS/(d₀+Δx)；当 |Δx| ≪ d₀ 时，ΔC ≈ −C₀·Δx/d₀，因此测出 ΔC 即可反推尖端位移。

EXTENSION · CAPACITIVE MICRO-DISPLACEMENT SENSING

拓展应用：微创手术机器人尖端的实时微位移监测

应调节的物理参数：固定极板面积 S 和介质 εr，让器械尖端（或被测量组织）带动一块极板，使极板间距 d 随微小位移改变。此时 C = ε₀εᵣS/d，通过测量电容变化 ΔC 即可反推位移 Δx。

提高灵敏度的方法：减小初始间距 d₀（灵敏度约与 1/d₀² 成正比）、增大极板面积 S、选用更高 εr 的介质、采用差分电容结构（灵敏度约 ×2，并抑制温度漂移与共模干扰）、提高电容检测电路的分辨率（fF 级）。平台中把 Δx 调到 ±2 μm，就能看到 fF 级 ΔC 与 μm 级分辨率的变化。

与力反馈结合：电容传感负责“尖端移动了多远”，力传感器负责“接触力有多大”；两者构成闭环，可实时校正器械位置与接触力，避免组织损伤。这也是平行板电容器从课堂公式走向微创手术机器人的典型路径。
